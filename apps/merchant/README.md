# Kartop — приложение магазина (Flutter)

Кабинет магазина: заказы, сборка, выдача по коду (экран курьера), ассортимент,
настройки доставки/самовывоза. Веб-кабинета нет — всё из мобильного приложения.

## Экраны

- **Вход** — по OTP (Telegram → WhatsApp → SMS, как на бэкенде).
- **Мои магазины** — выбор магазина (сотрудник может быть в нескольких).
- **Заказы** — список (активные/завершённые), статусы, доставка/самовывоз.
- **Заказ** — состав, ПДн клиента (после принятия), оплата; действия по статусу:
  принять → сборка (взвешивание/нет в наличии) → готов → в доставку/к выдаче.
- **Курьер** — ввод 4-значного кода получения (клиент называет при передаче) → заказ закрыт.
- **Товары** — цены и наличие (переключатель), правка цены.
- **Настройки** — самовывоз вкл/выкл, лид-тайм, выход.

## Запуск

```bash
flutter pub get
# Android-эмулятор (хост доступен как 10.0.2.2):
flutter run --dart-define=API_BASE=http://10.0.2.2:3000/api
# Реальное устройство/прод:
flutter run --dart-define=API_BASE=https://api.kartop.kz/api
```

API должен разрешать CORS для клиента (на бэкенде включается `app.enableCors`,
origin настраивается `CORS_ORIGINS`).

## Структура

```
lib/
  config.dart        базовый URL API (--dart-define=API_BASE)
  theme.dart         тёплая палитра «Морковь» + Material 3
  models.dart        модели (деньги в тиынах, вес в граммах)
  api.dart           HTTP-клиент к API (+ ApiException)
  session.dart       токен (persist) и выбранный магазин (ChangeNotifier)
  format.dart        форматирование денег/веса/статусов/дат
  screens/           login, stores, home, orders, order_detail, courier, catalog, settings
```

Проверено: `flutter analyze` — чисто; `flutter test` — зелёно; `flutter build web` —
собирается; все экраны прогнаны против живого API (вход, заказы, сборка, курьер, товары).
