# 13. Автотесты

Юнит-тесты на Jest + ts-jest для корректности бизнес-логики (без БД — быстро и
детерминированно). Запуск: `npm test` (из корня — по всем воркспейсам, `--if-present`)
или `npm test` в `apps/api`.

## 13.1 Покрытие (25 тестов)

| Файл | Что проверяет |
|------|---------------|
| `ordering/order-state.spec.ts` | машина состояний: разрешённые переходы, запрет перескоков/откатов, отмена только из активных, ПДн скрыты до ACCEPTED |
| `ordering/ordering.service.spec.ts` | арифметика суммы (весовой = цена×г/1000, штучный = цена×кол-во), эмиссия `order.placed`, валидации (qtyG, магазин не найден, недоступный товар) |
| `billing/billing.service.spec.ts` | выставление счетов всем активным подпискам, **идемпотентность** (не дублировать за месяц), период в UTC |
| `notifications/templates.spec.ts` | аудитория каждого события (customer/merchant/both), флаги critical/loud, тексты не падают на пустом payload |
| `common/csv.spec.ts` | экранирование CSV (запятые/кавычки/переводы строк), BOM, CRLF, тиын→тенге, ISO-даты |

## 13.2 CI

`.github/workflows/ci.yml` на каждый push в `main` и PR:
`npm ci` → `prisma generate` → `lint` → `build` → `test`.
