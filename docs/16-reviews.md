# 16. Оценки и отзывы

После доставки/выдачи покупатель оценивает заказ (1–5 ★) и может оставить комментарий.
Рейтинг магазина пересчитывается из реальных отзывов.

## 16.1 Модель

`Review { orderId @unique, storeId, customerId?, rating 1..5, comment?, createdAt }`.
Один отзыв на заказ. `Store.rating` и `Store.reviewCount` пересчитываются (среднее, кол-во).

## 16.2 API (публичные)

| Метод | Путь | Назначение |
|-------|------|------------|
| POST  | `/orders/:id/review` | оставить отзыв `{ rating 1..5, comment? }` |
| GET   | `/shops/:slug/reviews` | рейтинг, кол-во и последние отзывы |

Правила: только статус `DELIVERED`/`COMPLETED` (иначе 400), один раз на заказ
(повтор → 409), оценка 1..5 (иначе 400). `GET /orders/:id/track` возвращает
`canReview` и уже оставленный `review`.

## 16.3 Веб

- Страница трекинга: при `canReview` — форма (звёзды + комментарий); после отправки —
  «Спасибо за оценку». Если отзыв уже есть — показывается.
- Витрина: в шапке рядом с рейтингом — число отзывов.

## 16.4 Проверено

- Юнит-тесты (5): приём отзыва и пересчёт рейтинга, диапазон 1..5, только
  доставленный, повтор → конфликт, заказ не найден. Итого 39 passed.
- Браузер: заказ доведён до DELIVERED → форма отзыва → 5★ + комментарий →
  рейтинг магазина 4.9→5.0, count 0→1; повтор → 409, недоставленный → 400.
