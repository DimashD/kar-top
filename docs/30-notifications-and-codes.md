# 30. Коды входа и уведомления: провайдеры и ключи

Что уже работает в коде и что нужно завести владельцу, чтобы оно заработало на проде.

## Как это устроено

**Коды входа (OTP).** Пробуем каналы по очереди, пока один не доставит:
почта (если указан email) → Telegram → WhatsApp → SMS. Канал без ключа просто пропускается.
На тесте (test.kar-top.kz) код всегда `111111` — ничего не тратим.

**Уведомления о заказах.** Пуш в приложение (Firebase). Покупателю без приложения важные
статусы (оформлен, принят, нужен ответ, собран/готов, отменён) могут уходить SMS — включается
`NOTIFY_SMS_FALLBACK=1`, это платно.

| Событие | Магазину | Покупателю |
|---|---|---|
| Новый заказ | пуш со звуком (повтор до принятия) | «Заказ оформлен», код получения |
| Принят | — | «Магазин принял заказ» |
| Собирают | — | «Собираем заказ» |
| Нужно уточнить | — | «Магазин позвонит вам» |
| Нет позиции | — | «Убрали позицию …» |
| Собран | — | готов к самовывозу / скоро передадим курьеру, итог |
| В пути | — | «Курьер везёт заказ» |
| Получен | — | просьба оценить |
| Отзыв | «Новый отзыв ★★★★★» | — |
| Отменён | да | да |

## Какие ключи завести

Ключи кладутся в **GitHub → Settings → Secrets and variables → Actions** репозитория
(имя секрета = имя переменной ниже), затем **Actions → Server ops → apply-provider-keys** —
задача перенесёт заданные ключи в `.env.prod` на сервере и перезапустит API.
Пустые секреты не трогают то, что уже есть на сервере.

### 1. SMS — SMSC.kz (запасной канал, работает на любом телефоне)
1. Регистрация на smsc.kz, договор как ТОО/ИП.
2. Личный кабинет → Настройки → включить «пароль для API» (отдельно от пароля входа).
3. Имена отправителей → заявка на имя `Kartop` (одобрение операторами KZ — несколько дней).
4. Пополнить баланс.

Секреты: `SMSC_LOGIN`, `SMSC_PASSWORD` (пароль API), `SMS_SENDER_NAME` = `Kartop`.

### 2. Telegram Gateway (самый дешёвый канал для кодов)
1. gateway.telegram.org → войти по номеру Telegram.
2. Пополнить баланс (оплата в TON/через Fragment), скопировать API-токен.
Код приходит в Telegram от официального аккаунта «Verification Codes». Платим только
за доставленные коды.

Секрет: `TELEGRAM_GATEWAY_TOKEN`.

### 3. WhatsApp — Meta Cloud API (официальный канал)
1. business.facebook.com → создать Business Manager, пройти верификацию компании.
2. developers.facebook.com → приложение типа Business → продукт WhatsApp.
3. Добавить номер телефона компании (на нём не должно быть обычного WhatsApp).
4. WhatsApp Manager → Шаблоны → новый шаблон категории **Authentication**,
   имя `kartop_otp`, язык Russian, кнопка «Скопировать код». Дождаться одобрения.
5. Business Settings → Системные пользователи → создать, выдать доступ к приложению и WABA,
   сгенерировать постоянный токен с правами `whatsapp_business_messaging`.
6. Скопировать Phone number ID (WhatsApp → API Setup).

Секреты: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`.

### 4. Почта (коды на email)
Любой SMTP: Яндекс 360 для бизнеса, Mail.ru для бизнеса, Brevo, Amazon SES.
Нужен ящик вроде `no-reply@kar-top.kz` и записи SPF/DKIM в DNS домена (их даёт провайдер).

Секреты: `SMTP_HOST`, `SMTP_PORT` (обычно 465), `SMTP_USER`, `SMTP_PASS`,
`EMAIL_FROM` = `Kartop <no-reply@kar-top.kz>`.

### 5. Резервные SMS о статусах
Секрет `NOTIFY_SMS_FALLBACK` = `1` — включить, не задавать — выключено.

### 6. Пуши в клиентском приложении — Firebase
Один раз: **Actions → Server ops → Run workflow**, ветка `develop`, задача
`firebase-customer-app`. Задача регистрирует в Firebase приложения `kz.kartop.app` и
`kz.kartop.app.staging` и печатает в логе их `google-services.json` — их добавляем в
`apps/customer`, после чего приложение начинает получать пуши.
Приложение магазина уже подключено.

## Сколько это стоит (ориентиры, ноябрь 2026)

| Канал | Цена за сообщение | Комментарий |
|---|---|---|
| Telegram Gateway | ~$0.01 за доставленный код | дешевле всего, если у человека есть Telegram |
| WhatsApp (Authentication, KZ) | ~$0.02 | по прайсу Meta; почти у всех в KZ есть WhatsApp |
| SMS через SMSC.kz | ~13–20 ₸ | местный тариф с именем отправителя; смотрите прайс в кабинете |
| SMS через Twilio/Plivo | ~$0.27–0.35 | международные — заметно дороже, поэтому SMSC.kz |
| Email | почти бесплатно | только если человек указал почту |
| Пуш (Firebase) | бесплатно | основной канал уведомлений |

Порядок каналов выбран от дешёвого к дорогому, поэтому SMS уходит только тем, до кого
не дошли остальные.
