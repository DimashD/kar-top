# 12. Веб-витрина покупателя (Next.js)

Customer — web-first PWA. Витрина открывается по короткой ссылке `kartop.kz/<slug>`,
рендерится на сервере (SSR) для SEO/OpenGraph, корзина и оформление — на клиенте.

## 12.1 Структура (`apps/web`)

```
app/layout.tsx         шрифт Golos, метаданные, theme-color «Морковь»
app/globals.css        токены дизайна (--carrot #D9531E, --leaf, кремовый фон), кнопки, карточки
app/page.tsx           лендинг: hero, категории базара, «как это работает»
app/[slug]/page.tsx    SSR витрина: fetchCatalog → <StoreView>
components/StoreView.tsx  клиент: каталог, корзина, чекаут, подтверждение
lib/api.ts             базовый URL API (SSR внутренний / клиент относительный /api), типы каталога
lib/format.ts          деньги (тиын→₸), вес (г→кг), подписи единиц
```

## 12.2 Поток покупки

1. SSR грузит `/api/shops/<slug>/catalog`, группирует товары по категориям.
2. Карточки: серый плейсхолдер фото (реальных снимков пока нет), цена, «за кг/шт»,
   бейджи «Акция» / «Свежее» (perishable).
3. Корзина: весовые добавляются шагом `stepG` (или 500 г), штучные — по 1 шт; ±.
4. Чекаут: телефон (`+7XXXXXXXXXX`), адрес, способ оплаты при получении
   (наличные / карта курьеру / Kaspi) → `POST /api/orders` (гостевой, @Public).
5. Подтверждение: номер заказа, оценочная сумма, напоминание «точная сумма —
   после взвешивания; данные магазину — после принятия».

## 12.3 Связь с API

- Клиент всегда ходит на относительный `/api`.
- **Прод:** Caddy маршрутизирует `/api/*` → сервис `api`, остальное → `web`
  (см. `deploy/Caddyfile`). Веб-контейнер не видит `/api`.
- **Локально без Caddy:** `API_PROXY_TARGET=http://127.0.0.1:3000` на этапе `build`
  включает rewrite `/api/:path*` в `next.config.js`.
- SSR-фетч использует `API_BASE_INTERNAL` (в контейнере — `http://api:3000/api`).

## 12.4 Безопасность версии

Next.js зафиксирован на `14.2.33+` (в репо — `14.2.35`): закрыты критичные
обход авторизации middleware (CVE-2025-29927) и SSRF редиректов. Оставшийся
advisory про DoS в Server Components закрывается только мажором (Next 16) —
вынесено в бэклог.

## 12.5 Проверено e2e (Playwright, 420×900)

Открытие витрины → добавление товаров → корзина → телефон/адрес → Kaspi →
«Оформить» → `Заказ №N принят`. Заказ создан в БД (`PLACED`, верный адрес и
способ оплаты), магазину ушёл пуш (outbox `order.placed`), ошибок в консоли нет.
