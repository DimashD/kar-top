# 17. Стимул скачивания приложения покупателем

Ссылка-трекинг ведёт на страницу, которая мотивирует установить приложение
(живой статус, пуши), оставляя код получения под рукой.

## 17.1 Где

- **Страница трекинга** `/order/<id>`: под кодом получения — баннер
  «Следите за заказом в приложении» (пока заказ не доставлен). Статус и сумма — ниже.
- **Лендинг** `/app`: «Приложение Kartop» + кнопки сторов. Ссылка «Приложение» в шапке главной.
- **Уведомление покупателю** (`order.placed_customer`): «…Следите за заказом в приложении: <ссылка>».

## 17.2 Поведение

`components/AppBanner.tsx` (клиент): определяет платформу по `navigator.userAgent`.
- iOS → кнопка App Store; Android → Google Play; десктоп → обе.
- «Открыть в приложении» — диплинк `kartop://order/<id>`; если приложение не
  установлено, через ~1.2 c уводит в стор.

## 17.3 Конфигурация

Ссылки сторов и схема диплинка — через окружение (плейсхолдеры до релиза):
`NEXT_PUBLIC_IOS_APP_URL`, `NEXT_PUBLIC_ANDROID_APP_URL`, `NEXT_PUBLIC_APP_SCHEME`.
Заменить на реальные после публикации в App Store / Google Play.

## 17.4 Проверено

Браузер: iOS-UA → баннер с App Store и «Открыть в приложении» на трекинге;
десктоп → лендинг `/app` с обеими кнопками; код получения остаётся виден; без ошибок.
