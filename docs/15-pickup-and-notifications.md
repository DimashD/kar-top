# 15. Самовывоз, уведомление покупателя и плейсхолдеры категорий

## 15.1 Способ получения: доставка или самовывоз

У заказа появился `Order.fulfillment` (`DELIVERY` | `PICKUP`) и `Order.pickupAt`.
Магазин настраивает самовывоз: `Store.pickupEnabled` и `Store.pickupLeadMinutes`
(минимум времени от оформления до готовности к выдаче).

- Оформление (`POST /orders`): поле `fulfillment` (по умолчанию `DELIVERY`) и `pickupAt` (ISO).
  - `PICKUP` и `pickupEnabled=false` → `400`.
  - `pickupAt` раньше, чем оформление + `pickupLeadMinutes` → `400` (с допуском 60 c на дрейф секунд).
  - при `PICKUP` адрес не требуется и не сохраняется.
- Публичный каталог отдаёт `pickupEnabled` и `pickupLeadMinutes` — витрина предлагает
  самовывоз и подставляет «не ранее чем через N мин».
- Трекинг и веб-страница показывают способ получения, время самовывоза и адрес магазина;
  степпер адаптируется (В пути → «Готов к выдаче», Доставлен → «Выдан»).

### Настройки магазина

```
GET   /merchant/stores/:id/settings
PATCH /merchant/stores/:id/settings   { pickupEnabled?, pickupLeadMinutes?, deliveryMode? }
```

Только `OWNER`/`MANAGER` (проверка членства). Веб-кабинета нет — из приложения магазина.

## 15.2 Уведомление покупателю при оформлении

Новое событие `order.placed_customer` (аудитория — покупатель, `critical`): сразу
после оформления покупатель получает пуш (при отсутствии — резервный SMS) с номером
заказа, **кодом получения** и **ссылкой-трекингом** (`WEB_BASE_URL/order/<id>`).
`WEB_BASE_URL` задаётся в окружении API (по умолчанию `https://kartop.kz`).

Эмитится в той же транзакции, что и `order.placed` (магазину). Проверено e2e:
диспетчер отправил покупателю «Заказ оформлен … Код получения … Отслеживайте: …».

## 15.3 Красивые плейсхолдеры по категориям

Когда у товара нет фото, карточка показывает тематичную «категорию»: мягкий градиент
+ иконка + название категории (`apps/web/lib/category.ts`, подбор по ключевым словам).
Как только у `MasterProduct.media.url` появляется фото — рендерится оно (см. docs/14).

## 15.4 Проверено

- Юнит-тесты (34): самовывоз (без адреса, выключен → 400, раннее время → 400,
  корректное время проходит), `order.placed_customer` эмитится.
- Браузер (Playwright): переключение Доставка/Самовывоз, выбор времени, заказ №15
  создан как `PICKUP` без адреса; трекинг показывает самовывоз, время и адрес магазина;
  плейсхолдеры категорий отрисованы.
