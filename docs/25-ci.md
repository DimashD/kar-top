# 25. CI/CD

## 25.1 Зачем нужна CI-сборка

CI (Continuous Integration) — сервер, который на каждый `git push` автоматически:
- **проверяет код** (линт, анализ, тесты) — ловит ошибки до того, как они попадут
  пользователям, и не даёт «сломанному» коду оказаться в `main`;
- **собирает приложения** (Android `.aab`, iOS `.ipa`, бэкенд/веб) без ручной возни на
  локальной машине — одинаково и воспроизводимо;
- выдаёт готовый файл сборки (артефакт), который можно сразу загрузить в Google Play /
  App Store.

Выгода: меньше ручной работы и ошибок «у меня собиралось», готовый релиз в пару кликов,
уверенность, что в `main` всё зелёное. Особенно полезно для iOS — GitHub даёт macOS-раннеры,
поэтому `.ipa` можно собирать без собственного Mac.

## 25.2 Что настроено (GitHub Actions)

- `.github/workflows/ci.yml` — бэкенд/веб: `npm ci` → prisma generate → lint → build → test
  на каждый push/PR.
- `.github/workflows/mobile.yml` — приложение магазина:
  - **analyze** (на каждый push/PR): `flutter analyze` + `flutter test` — быстро, без секретов;
  - **android-release** (вручную «Run workflow» или по тегу `vX.Y.Z`): собирает подписанный
    `.aab`, кладёт в артефакты;
  - **ios-build** (на macOS-раннере, вручную/по тегу): компиляция iOS (`--no-codesign`);
    подписанный `.ipa` — после настройки Apple-секретов.

## 25.3 Секреты репозитория (GitHub → Settings → Secrets and variables → Actions)

Для релизной сборки Android добавить **секреты**:
- `ANDROID_KEYSTORE_BASE64` — keystore (`.jks`) в base64: `base64 -w0 kartop-merchant.jks`
- `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`, `ANDROID_KEY_ALIAS`

Опционально **переменная** `API_BASE` (иначе берётся `https://api.kartop.kz/api`).

Для подписанного iOS later понадобятся Apple-секреты (сертификат .p12, provisioning
profile, пароль) — добавим, когда будет Apple Developer аккаунт.

## 25.4 Как выпускать релиз

1. Поднять версию в `apps/merchant/pubspec.yaml` (`version: 1.0.1+2`).
2. Либо нажать «Run workflow» у `mobile.yml`, либо поставить тег:
   `git tag v1.0.1 && git push origin v1.0.1`.
3. Скачать `.aab` из артефактов job и загрузить в Google Play (iOS — из macOS-сборки).
