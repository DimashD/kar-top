# 06. Разбор витрины Kartop (kar-top.kz/dimash-market)

Дата: 31.10.2026. Пройден путь покупателя на телефоне: витрина → товар → корзина → адрес → оформление. Заказ не отправлялся.

## Что это
Веб-витрина «ларька у подъезда»: один магазин, короткая ссылка или QR у прилавка, оплата при получении. Стек: Next.js (App Router) + отдельный API (по формату ошибок — NestJS), то есть тот же стек, что у нас. Лендинг «Скоро в Алматы».

## Что берём (работает лучше, чем у нас)

| # | Решение Kartop | Почему хорошо | Как переносим |
|---|---|---|---|
| 1 | **Бесплатные карты: MapLibre + свои тайлы Алматы (PMTiles, ~31 МБ) + свой поиск адресов** | 0 ₸ за карты, номера домов и корпусов (309/1) видны, нет лимитов и ключей | Делаем это вариантом карт по умолчанию для MVP. 2GIS — опция, если не хватит качества адресов |
| 2 | **Проверка зоны с первого экрана**: «Укажите адрес — проверим зону», ответ «в зоне доставки, до магазина 8 м» | Покупатель не собирает корзину впустую | Плашка проверки адреса в шапке витрины и итог «Возим сюда / не возим» |
| 3 | **Оформление без регистрации**: только телефон | Минимум трения на первом заказе | Гостевой заказ по телефону; SMS-код один раз, при первом заказе (защита от фейков) |
| 4 | **Доставка / Самовывоз** переключателем в оформлении | Ясный выбор вверху формы | Добавили в макет оформления |
| 5 | **Человеческие окна времени**: «Как можно скорее (~час)», «Сегодня до 23:00», «Завтра утром / днём / вечером» + «продавец позвонит сам» | Ларьку проще, чем строгие слоты с лимитами | Режим «простые окна» по умолчанию; строгие слоты с лимитами — включаемая опция для магазинов с курьерами |
| 6 | **Шаг веса у каждого товара**: зелень 100 г, помидоры 500 г, картофель 1 кг; вес показывается в граммах | Точно под реальную торговлю | У нас уже в модели (`step_g`), берём отображение «500 г» |
| 7 | **Полоска до минимальной суммы** в нижней кнопке корзины | Мотивирует добрать | Уже есть «до бесплатной доставки»; добавляем «до минимума» |
| 8 | **Пауза магазина** (`isPaused`, `pausedUntil`) | Продавец отошёл — витрина честно говорит «на паузе до 15:30» | Кнопка «Пауза на 30 / 60 мин» в приложении магазина |
| 9 | **QR-код у прилавка** | Офлайн-покупатели магазина становятся онлайн-клиентами бесплатно | Приложение магазина печатает QR-плакат и наклейку; экран «Поделиться витриной» |
| 10 | **Позиционирование «прилавок в двух шагах от подъезда»** | Понятная гиперлокальная идея, не конкурирует с Wolt лоб в лоб | Используем в маркетинге и онбординге |
| 11 | **Общие фото каталога** (`photo/seed/tomato.jpg`, ключ `sign`) | Магазину не надо фотографировать товар | Подтверждает наш мастер-каталог |
| 12 | **Шрифт Golos** (кириллица + казахский) | Очень читаемый интерфейсный шрифт | Оставляем Onest, Golos — запасной вариант; оба бесплатные |

## Что у них слабо (делаем лучше)

| Проблема | Последствие | У нас |
|---|---|---|
| `noindex` на витрине, заголовок у всех страниц «Kartop», нет sitemap и превью для соцсетей | Ссылка в WhatsApp или Instagram без названия и фото, Google не находит магазин | SSR + название магазина в заголовке, OpenGraph-превью с фото, sitemap |
| На карточке товара текст цены обрезан («Примерно 100 ₸ за 50…»), нет описания и «≈ шт» | Непонятно, сколько штук приедет | Шторка с «≈ 3–4 шт», пресеты веса |
| Подсказки адреса дублируются (4 раза «309») | Путаница при выборе | Склеиваем дубли, показываем ЖК и подъезды |
| Телефон без подтверждения | Фейковые заказы, ларёк возит впустую | SMS-код на первом заказе |
| Стоимость доставки нигде не показана | Сюрприз при получении | Цена доставки видна на витрине и в итоге |
| Нет поиска, рейтинга, часов работы на витрине | Меньше доверия, сложно при большом ассортименте | Есть в наших макетах |
| Только веб, нет push-уведомлений | Покупатель не узнает о замене или пересчёте суммы | Приложение + push; на вебе — web push и SMS |
| Много капса и декоративный фон «волны» | Хуже читается | Спокойная типографика |
